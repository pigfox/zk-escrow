# audit-allowlist.txt — 64-hex values in audit/ that are PUBLIC BY CONSTRUCTION.
#
# A keccak hash and a private key are both uniform 32-byte values, so nothing
# about their shape separates them. `forge test -vvvv` traces are full of the
# former. Rather than weaken the secret scan or exempt test.log — the one file a
# leaked key would most likely land in — each public value is listed here BY VALUE
# with the reason it is public. Anything not listed still fails the scan.
#
# Every entry below was classified by hand in PF-S125. Adding one is a claim that
# a specific value is public, and it is reviewed like any other suppression.

# The ERC-1967 implementation slot: keccak256("eip1967.proxy.implementation") - 1.
# A standardised constant published in the EIP itself, read by every UUPS proxy in
# existence. It appears in these traces because the upgrade tests read the slot
# directly via VM::load to prove where the proxy points.
360894a13ba1a3210667c828492db98dca3e2076cc3735a920a3ca505d382bbc

# Event topic hashes — keccak256 of an event's signature string. Public by

# filtered. These two appear in decoded log tuples in the dispute and settlement
# tests.
